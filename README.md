## Примечания
- Все страницы используют общий файл `styles.css`.
- Переключатель языков: **EN / 中文**.
- На страницах с диаграммами (Эль-Ниньо, атмосфера, конвейер) оставлены плейсхолдеры под изображения музея.
- При необходимости можно добавить отдельные страницы для этикеток витрин (корабли, полёт, соль, лёд, приборы и т.д.) в том же стиле.
